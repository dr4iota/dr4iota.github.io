Building for Apple Platforms

Currently, macOS builds are limited to Intel (x86_64). Our existing Mac cannot run the modern Apple toolchain, so creating or testing iOS apps is not possible, nor can we produce universal Apple-silicon macOS binaries.

We will need to obtain a new Apple Silicon Mac once sufficient funding is available. This will allow us to:

  • Build and ship universal macOS apps (Apple Silicon + Intel).
  • Develop, test, and publish iOS apps for iPhone and iPad.
  • Maintain an up-to-date toolchain for security, performance, and compatibility.

At a glance

Current Limitation

macOS builds are Intel-only; no iOS builds.

Root Cause

The development Mac is too outdated for modern Apple SDKs.

Solution

Acquire an Apple Silicon Mac to access modern toolchains.

Reach more users

Universal binaries ensure smooth performance on M-series Macs while still supporting Intel users.

Build for iOS

We can finally compile, test, and ship apps for iPhone and iPad.

Improve quality

Modern SDKs enable better security, accessibility, and reliability for everyone.
