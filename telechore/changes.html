What's new

What each version changed. A line marked with a platform holds there only.

0.5.0 — unreleased

  • A link in a previewed HTML file can no longer act in the app.
  • The lens keeps a fixed-size terminal whole on screen, the part you work in at full size and the rest squeezed toward the edges.
  • The lens opens at Fill, the screen covered, and zooms out to Fit, the whole terminal with nothing squeezed.
  • Standard is now Flat, and pans at the full frame rate with far less graphics memory.
  • Largest zoom sets how far you can zoom in, 1× to 5× the default type size.
  • Save the view on screen as the terminal's start, one for each orientation.
  • A default type size per server, and weights from Thin to Medium for JetBrains Mono.
  • The cursor follow and Find glide to where they go, rather than jump.
  • A message in the terminal's header is said once, in the header or under it.
  • The clipboard menu closes as soon as anything is typed.
  • The full keyboard is drawn behind the text by default, with the text solid over the keys.
  • A keyboard setup per server, with a default for the rest, from the wrench on the keyboard menu.
  • The keyboard menu is simpler, one keyboard per branch.
  • The Coder keys are half a key wider, and have Caps Lock.
  • Overlapping taps on the full keyboard are no longer lost, and a finger between keys does nothing.
  • Reach a server through another you saved, a jump host, with Through on the Server tab.
  • A server with no file access (SFTP) still opens its terminal.
  • Encrypted EC keys, and keys under AES-256, open.
  • A field too long says so at the field, with a count.
  • Export puts in a code only the passwords that are saved.
  • A kept copy the server has moved past wears a torn bookmark, and its press is Forget.
  • Opening a kept folder says what it fetches.
  • An execute bit crosses a copy only where the file runs at the other end.
  • Termoasis's console games, eighteen of them, under Games, kept like a terminal, and on the website too.
  • A Licences page under Usage lists what the app is built with.
  • Android The system keyboard's suggestions and corrections work, and a password is kept out of its view.
  • Android On a short screen the header steps aside while the system keyboard is up.
  • Android Kept terminals are checked when you come back to the app.
  • Android A folder or key file picked while the phone restarted the app is opened, not dropped.
  • Android A shared folder that has gone is named, rather than a 502 page.
  • Android A tap on the terminal brings the keyboard back after a system box.
  • desktop An SSH alias's ProxyJump is followed, through your own servers or as ssh would.
  • desktop Ctrl+Shift+V pastes into the password box.
  • Windows Pro is on sale in the Microsoft Store, one payment for as many servers and kept terminals as you like.

0.4.1 — 13 October 2026

  • A connection that drops while you watch reconnects on its own, as soon as there is a network.
  • Try again takes the place of the keys when a connection cannot be made.
  • What you type while the password box goes away is kept, and sent once the connection is up.
  • On a narrow screen the terminal's header keeps its line for the server's name.
  • Nothing sits under a notch, a rounded corner or the gesture strip.
  • Closing Find takes all its highlights with it.
  • A typeface per server, the system's monospace or JetBrains Mono, which comes with the app.
  • Android The system keyboard stays down while the keys menu or the list of terminals is open.
  • Android A reconnect that could not be made is tried again on its own when the phone moves between Wi-Fi and mobile data.
  • desktop Log in through the SSH agent this computer already runs — ssh-agent, the OpenSSH Authentication Agent or Pageant.
  • desktop The key files your ~/.ssh/config names for a server are offered, certificates included, and a security key works through the agent.
  • A folder's rows have nothing behind ⋯. Tap a file's or folder's icon to keep it offline; Forget and Update are on the line under it.
  • Keep a whole folder offline. It is counted first, and new or changed files come the next time you open it.
  • Update fetches the newer copy of a file the server has changed, without opening it.
  • CSV and TSV open as a table, JSON is laid out, and a .gz file opens unpacked.
  • Raw shows a file as text, and an HTML file's Preview is the page drawn, with scripts off.
  • Preview, Source and Raw are an eye, </> and a sheet, and what can be done with a file is one joined button.
  • New folder's name box takes the filter's place, and a filter's matches are the same rows as the folder's.
  • The tree marks what is kept offline, and Pinned is now Starred, with a star.
  • Cache says plainly what is held and how much can be reclaimed, and when each folder last got a copy.
  • Replacing a file on a server keeps its mode, so a script stays executable.
  • A screen reader names a row's controls, and what a kept row holds.
  • A new server never replaces one already saved under the same Id.
  • Android On a phone the header takes a row less, and the sidebar slides in under the menu button.
  • Android Back over a server's unsaved changes asks before leaving them.
  • Android A password typed while the app was put aside still logs in, rather than failing to send.

0.4.0 — 9 October 2026

  • Keep a terminal running when you leave it, and come back to it as you left it. The free edition keeps as many running as it saves servers.
  • Switch between the terminals you left open, close one, or open another on the same server.
  • Back from the background, a kept terminal that lost its connection reconnects on its own.
  • A terminal says why it ended: the shell exited, or the connection was lost.
  • Each server lists the terminals you left open, and has a New terminal button.
  • Hold a finger on a link in the terminal to open it or copy it.
  • A terminal refits when its window changes size, even after you have typed in it.
  • With a hardware keyboard, the terminal follows the cursor as you type, and is noticed, so a terminal with no keyboard of your choosing yet opens without the extra keys.
  • desktop Show a terminal in a window of its own; quitting with terminals open asks first.
  • Windows The window opens where you left it, at the size you left it, maximized if it was.
  • Linux The window opens at the size you left it, maximized if it was.
  • Linux Install from a .deb or an .rpm, which bring the libraries it needs and put it in your menu.
  • Android The system keyboard no longer covers the terminal on older phones.
  • Android A phone too old for the terminal says what to update, instead of a blank screen.
  • Android Back closes the list of terminals, the keys menu or Find before it leaves the terminal.
  • Android Choosing our keyboard puts the system keyboard away.
  • Android The status bar follows the app's light or dark theme.
  • Files you opened on a server stay readable when it cannot be reached, and a file that has not changed is not fetched again.
  • Keep offline keeps a file on this device until you forget it. Cache, in Places, shows everything held.
  • New folder and Upload in a server's folders, with progress and Cancel.
  • A file's ⋯ holds what can be done with it: Download, Delete, Keep offline, Forget copy.
  • Delete a file or an empty folder on a server. It asks every time.
  • desktop New folder and Upload in your own folders too, and Delete moves to the Trash or Recycle Bin.
  • Android Download asks where to save the copy.
  • A server's folder reconnects on its own when its connection has dropped, and a download cut off picks up where it stopped.
  • Buttons show a mark beside their word, and a switch is lit when it is on. Pane is now Sidebar.
  • As root is a button in a folder's header.
  • Times are in your own time zone, not UTC.
  • A folder pinned on a server is named with its path, as Recent names it.
  • A server that takes only keys says so, instead of asking for a password it would refuse.
  • Website, at the top left of the start page, opens Telechore's website.
