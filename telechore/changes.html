Telechore Usage What's new

What's new

What each version changed. A line marked with a platform holds there only.

0.4.0 — 9 October 2026

  • Keep a terminal running when you leave it, and come back to it as you left it. The free edition keeps as many running as it saves servers.
  • Switch between the terminals you left open, close one, or open another on the same server.
  • Back from the background, a kept terminal that lost its connection reconnects on its own.
  • A terminal says why it ended: the shell exited, or the connection was lost.
  • Each server lists the terminals you left open, and has a New terminal button.
  • Hold a finger on a link in the terminal to open it or copy it.
  • A terminal refits when its window changes size, even after you have typed in it.
  • With a hardware keyboard, the terminal follows the cursor as you type, and is noticed, so a terminal with no keyboard of your choosing yet opens without the extra keys.
  • desktop Show a terminal in a window of its own; quitting with terminals open asks first.
  • Windows The window opens where you left it, at the size you left it, maximized if it was.
  • Linux The window opens at the size you left it, maximized if it was.
  • Linux Install from a .deb or an .rpm, which bring the libraries it needs and put it in your menu.
  • Android The system keyboard no longer covers the terminal on older phones.
  • Android A phone too old for the terminal says what to update, instead of a blank screen.
  • Android Back closes the list of terminals, the keys menu or Find before it leaves the terminal.
  • Android Choosing our keyboard puts the system keyboard away.
  • Android The status bar follows the app's light or dark theme.
  • Files you opened on a server stay readable when it cannot be reached, and a file that has not changed is not fetched again.
  • Keep offline keeps a file on this device until you forget it. Cache, in Places, shows everything held.
  • New folder and Upload in a server's folders, with progress and Cancel.
  • A file's ⋯ holds what can be done with it: Download, Delete, Keep offline, Forget copy.
  • Delete a file or an empty folder on a server. It asks every time.
  • desktop New folder and Upload in your own folders too, and Delete moves to the Trash or Recycle Bin.
  • Android Download asks where to save the copy.
  • A server's folder reconnects on its own when its connection has dropped, and a download cut off picks up where it stopped.
  • Buttons show a mark beside their word, and a switch is lit when it is on. Pane is now Sidebar.
  • As root is a button in a folder's header.
  • Times are in your own time zone, not UTC.
  • A folder pinned on a server is named with its path, as Recent names it.
  • A server that takes only keys says so, instead of asking for a password it would refuse.
  • Website, at the top left of the start page, opens Telechore's website.

0.3.1 — 1 October 2026

  • Find in the terminal: tap the magnifier, or press Ctrl+Shift+F.
  • The keyboard on screen types the search, and nothing changes size.
  • Android Two servers are now free, up from one.
  • A greyed keyboard now says why: too narrow or too short for it.
  • The full keyboards are now called Laptop keys and Coder keys.
  • Windows The first release in the Microsoft Store.

0.3.0 — 29 September 2026

  • Telechore Coder: a full keyboard with every symbol on a key.
  • Five keyboard sizes, and keys colored by kind.
  • The extra keys repeat when held, and work with Ctrl and Alt.
  • Two fingers held still on the keyboard reset the view.
  • The floating header is easier to read, and keyboards can go over it.
  • Android Saved passwords are encrypted with the Android Keystore.

0.2.7 — 26 September 2026

  • Android Open a folder… works again after Android reopens the app.
  • Large files no longer freeze the app while they load.
  • A terminal starts in its folder, or in the server's Initial path.
  • A connected server shows a green dot.
  • One bad server entry no longer hides the others.
  • Install checks the server accepts a key before switching to it.

0.2.6 — 24 September 2026

  • Android Reopening the app could flash it on screen and close it. Fixed.
  • Reconnect with one tap when a session ends.
  • Two thumbs on the keys keep typing instead of starting a pinch.
  • Select text with a finger: hold, then drag.
  • All keys is laid out like a laptop's, with Fn and Shift lock.
  • The special keys have clearer signs; a tap between keys does nothing.

0.2.5 — 23 September 2026

  • Unlock Pro from a link on the home page.
  • Restore purchase now always says what it found.
  • Once Pro is bought, the footer says so, with no restart.
  • A purchase unlocks an import that is already open.
  • Plainer wording across the app.
  • With a keyboard: Esc closes a server form, Tab stays in dialogs.

0.2.4 — 22 September 2026

  • A code sent as text now works for 15 minutes, not one.
  • A scan that needs a password keeps the code — no second scan.
  • Backing out of the scanner no longer reports a camera failure.
  • A finished session stops holding the keyboard over its own message.
  • Tuning a keyboard's colours is free for everyone now.

0.2.3 — 16 September 2026

  • A window could stick on Opening… and never show what it opened. Fixed.
  • Opening a folder on a server no longer drops the connection it just made.
  • Android Turn or unlock the phone and the terminal comes back the right size.
  • Android Back out of Usage lands on the start page instead of leaving the app.
  • Bigger S, M and L in the keyboard menu, and Strong opacity finally works.

0.2.2 — 15 September 2026

  • A transfer code can no longer add a host key for a machine you already trust.
  • Scan a code from your desktop to bring its servers here — this now works.
  • The terminal says when a session ends, and keeps what you type while it dials.
  • Rotate a server's key: install a new one over the old without losing the login.
  • The Servers page says which row Save is waiting on, and reads its answers aloud.

0.2.1 — 12 September 2026

  • Copy and paste in the terminal, with the shortcuts every shell agrees on.
  • A press held on the shell opens Copy and Paste where your finger is.
  • A keyboard of ours opens where each server wants it, then drags anywhere.
  • Transfer codes carry more servers — host keys are yours to add.
  • Dragging a window resizes the far end once it settles, not every frame.

0.2.0 — 9 September 2026

  • The terminal keeps the size you set while the keyboard comes and goes.
  • Two fingers pan and zoom; a keyboard of ours floats over the shell.
  • Making or importing an SSH key asks how it gets onto the server.
  • Install a key over the login that already works, without leaving the app.
  • Move your servers to another device as a code the other one scans.

0.1.0 — 31 August 2026

  • First release. Browse a folder as a tree, or a machine you have an SSH login for, with a terminal on the same machine. Grant a folder on this device and it stays in Pinned.
