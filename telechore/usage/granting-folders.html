These pages are for Telechore 0.6.0 — what's new in it.

Granting folders

On Android the app cannot browse your storage on its own, so “Open a folder…” opens the system's folder picker, starting in Documents. The folder you choose is shared with the app, and Android remembers that across restarts.

The app asks for no storage permission. It can read only the folders you choose.

What that means in practice

  • A folder you choose is starred. It gets its own row under Starred, so opening it again never needs the picker. You can remove the row like any other. The folder stays shared with the app.
  • To stop sharing a folder, remove the folder itself — eject the card it is on, sign out of the account that serves it, or delete it. Android has no screen for withdrawing access to a single folder. The row stays in Starred, marked “denied”. Tapping it says the folder is no longer shared and offers “Choose again”, which opens the picker at that folder. Tap “Use this folder” and “Allow” to share it again. If a page from that folder is already open, browsing further into it reports the file as not found, instead of saying the folder is no longer shared. This is a known issue.
  • Places lists only what is always there. On Android that is these pages, and “Cache”, the copies this device keeps of your servers (see Files offline). Folders you choose go to Starred instead, so Places stays the same on every launch.

Files

“Files” is a folder that belongs to the app. It is private to the app, and it lasts until the app is uninstalled. It is listed in Places. Files that other apps hand over go there, by “Save to Telechore” or “Save to Files” (Opening files from other apps). “Delete” on a row removes the file, after asking. “Download” asks where to save a copy, so a download does not add a file to Files. A copy that an older version of the app saved in Files is still listed.
