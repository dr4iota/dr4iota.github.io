Granting folders

On Android, the app cannot browse your storage freely, so Open a folder… opens the system's folder picker, starting in Documents. The folder you choose is shared with the app, and Android remembers that across restarts.

The app asks for no storage permission; it can read only the folders you choose.

What that means in practice

  • A folder you choose is starred. It gets its own row under Starred, so opening it again never needs the picker. You can remove the row like any other; the folder stays shared with the app.
  • To stop sharing a folder, remove it — eject the card it is on, sign out of the provider that serves it, or delete it. Android has no screen for withdrawing access to a single folder. The row stays in Starred; tapping it says the folder is no longer shared, and Open a folder… shares it again. If a page from that folder is already open, browsing further into it reports the file as not found instead of saying the folder is no longer shared. This is a known issue.
  • Places lists what is always there: on Android, these pages, and Cache, what this device keeps of your servers (see Files offline). Folders you choose go to Starred instead, so Places stays the same on every launch.

Files

A folder of the app's own, private to it, which lasts until the app is uninstalled. It is listed in Places, as Files, only while something is in it: Download asks where to save a copy, so nothing new goes there, and a copy an older version of the app saved there is still offered.
