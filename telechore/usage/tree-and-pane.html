These pages are for Telechore 0.6.0 — what's new in it.

Tree and sidebar

The window has two halves. The tree on the left is the folder you opened. The rest of the window is the file you selected.

The tree

Directories come first, then other names, ignoring case. A directory has an arrow that opens it in place, and the app remembers which of those you left open. Files starting with a dot are not listed.

To start the tree at a folder further down, open it and press “As root” in the header.

The tree's heading is the open folder's name, and goes back to its top. It carries “Star”, to keep the open folder in Starred, and “Close”, to return to the start page. “Open a folder…” is at the foot of the sidebar, after Recent.

The sidebar

On the start page it holds the lists: Places, Starred, Recent, and any other list the app adds. Once a folder is open, the tree is at the top and those lists stay under it.

The header

The path, as links, and the controls for the window:

  • “Refresh” re-reads the folder or file and keeps your place. F5 and Ctrl+R do the same.
  • “Up” goes to the parent folder. At the top of the open folder the button is “Start” and returns to the start page.
  • “As root”, in a folder below the top, starts the tree at that folder.
  • “New folder” and “Upload”, in a folder the app can write to — on a computer, any of its own — add to it. New folder opens a row at the top of the table for the name. Upload asks for files, asks once before replacing any that are already there, and shows how far it has got in the status line, with “Cancel”.
  • Theme, line numbers and “Sidebar” are in Preferences.
  • “Print…”, in a file's “Send” menu, is on a rendered file or a source view, and prints that view.

Where the window is narrow the buttons show their marks only. Hold the header — its background, the name or the host, not a button — for about a second. It fills with colour as you hold, then every button shows its words, on as many rows as they need, and the rest of the window moves down. Tap the header's background again, or hold it, for the marks.

There is no Back button. Alt+Left, and the phone's gesture, go back one step. Forward is Alt+Right.
