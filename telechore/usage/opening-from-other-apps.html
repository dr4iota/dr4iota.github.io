Opening files from other apps

On Android

On Android, Telechore is offered for PDF and Markdown files in another app's Open with list and in its Share sheet, as two entries:

  • View in Telechore shows the file on its own, with no tree, marked Not saved: Telechore shows a copy that goes when you leave it. Save to Files, at the top left, keeps the copy in Files and shows it there. Start, beside it, goes to the start page and drops the copy.
  • Save to Telechore keeps the file in Files straight away and shows it there. A file of the same name with the same contents is the copy already there; one with other contents is kept beside it as name (2).

Telechore is never made the default. Android's Always makes it so, and you can change that in Android's settings for the app.

If a folder is open in Telechore, it is closed: the file takes its place, and the folder is in Recent. Back goes back to the app the file came from.

A Markdown file arrives on its own, so a picture or another file it links to beside it is not there to show.

Files you no longer want in Files can be removed with Delete on their row; there is no Trash on a phone, so it asks first.

On a computer

On Windows, Linux and macOS, Telechore is offered in Open with for PDF, Markdown and Mermaid files (.mmd, .mermaid; not on macOS yet). It is never made the default; your system's own setting does that. On a Linux desktop with nothing else set to open Markdown, the system may pick Telechore for it until you choose another.

The file is opened where it is, not copied, and shown on its own:

  • If nothing is open in Telechore — including when it was not running — it opens in the main window, with Show folder and Start at the top left.
  • Otherwise it opens in a window of its own, with Show folder and Main window. Opening the same file again brings its window to the front.

Show folder shows the file's folder as a tree, with the file still open; a PDF or a picture, whose page has room for nothing else, gives way to its folder's list, with the file's row lit. In the main window the folder then goes into Recent. A Markdown file's pictures and links to files beside it work, since its folder is there.

Sending a file to another app

On Android, a file's Send menu, at the right of its header, holds Open with… and Share…: the first offers the apps that open such a file, the second the system's share sheet. A file on a server is fetched first. Telechore is not offered to itself. The same menu holds Download… and Print….

A key's public line has Share beside Copy Public Key, on the Servers page, for sending it to another app without the clipboard.
