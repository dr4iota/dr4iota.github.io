These pages are for Telechore 0.6.0 — what's new in it.

Opening files from other apps

On Android

On Android, another app's “Open with” list and its share sheet offer Telechore for PDF and Markdown files, as two entries:

  • “View in Telechore” shows the file on its own, with no tree. The page is marked “Not saved”. Telechore is showing a copy, and that copy disappears when you leave it. “Save to Files”, at the top left, keeps the copy in Files and shows it there. “Start”, beside it, goes to the start page and drops the copy.
  • “Save to Telechore” puts the file in “Files” straight away and shows it there. If Files already has a file of the same name and the same contents, that existing copy is the one you see. If the name matches but the contents differ, the new file is kept beside it as name (2).

Telechore never sets itself as the default app. Choosing Android's “Always” does, and you can change that in Android's settings for Telechore.

If a folder is already open, Telechore closes it. The file takes its place, and the folder is left in Recent. “Back” returns to the app the file came from.

A Markdown file arrives on its own, so a picture or another file it links to, sitting beside it, is not there to show.

Files you no longer want in “Files” can be removed with “Delete” on their row. There is no Trash on a phone, so “Delete” asks first.

On a computer

On Windows, Linux and macOS, “Open with” offers Telechore for PDF, Markdown and Mermaid files (.mmd and .mermaid; Mermaid is not offered on macOS yet). Telechore never sets itself as the default. Your system's own setting does that. On a Linux desktop, if nothing else is set to open Markdown, the system may choose Telechore until you pick another app.

The file is opened where it is, not copied, and shown on its own:

  • If nothing is open in Telechore, including when Telechore was not running, the file opens in the main window. “Show folder” and “Start” are at the top left.
  • Otherwise the file opens in a window of its own, with “Show folder” and “Main window”. Opening the same file again brings that window to the front.

“Show folder” shows the file's folder as a tree, with the file still open. A PDF or a picture has no room on its page for a tree, so the page changes to the folder's list, with that file's row highlighted. In the main window the folder then goes into Recent. Pictures in a Markdown file, and its links to files beside it, work once the folder is open.

Sending a file to another app

On Android, “Send” at the right of a file's header holds “Open with…” and “Share…”. “Open with…” lists the apps that open this kind of file. “Share…” opens the system's share sheet. A file on a server is fetched first. Telechore does not offer itself. The same menu also holds “Download…” and “Print…”.

On the Servers page, next to “Copy Public Key”, a key's public text has “Share”, for sending that public key to another app without using the clipboard.
