Files offline

What you open on a server is kept on this device for a while, so the server can be browsed when it cannot be reached, and a file that has not changed is not fetched again.

A folder's rows

Everything a row offers is on the row.

  • The icon is Keep offline. A bookmark on it is outlined while the file or folder is not kept and filled when it is; tap the icon to switch. A file's own page has the same button. A grey bookmark is kept by its folder — or is a kept copy the server has changed since — and is not switched from there.
  • A line under the row says what this device has: Offline and when, for a kept copy, or Cached and when, for a file you only opened. After it is Forget, which removes the copy here; nothing on the server changes. Where the server has a newer file, Update at the line's end fetches it without opening it.
  • Keeping a folder keeps it and everything in it. It counts the folder first, then says how many files and how much, and asks. Hidden files and folders (names starting with .), node_modules, disk images and files a program generated are left out. A folder bigger than 2 GB on Android or 10 GB on a computer, or one that would leave this device with too little room, is refused. Files added or changed on the server come the next time you open their folder; when they come to more than 50 MB, Update on the folder's line fetches them. Forget on that line removes the folder's copies.
  • Download (the arrow at the row's end) saves a copy where you choose: a folder on a desktop, and the system's Save to… sheet on Android.
  • Delete (the bin) deletes the file, or an empty folder, from the server. It asks every time. A copy you kept offline stays, in Cache.

In the sidebar's tree, a bookmark after a name marks what you keep offline.

When the server cannot be reached

A server's folder opens from what this device has, with cannot be reached over the page and when the copy is from. Folders you never opened, and files you never fetched, are grey. Try again connects once the network is back.

Cache

Cache, in Places, lists the servers this device holds files from. Inside a server, each folder with a copy is one row, named by its path on the server — a long one with its start cut, … › pi › src — and inside that, its copies. A server's row says how much it holds in all, in how many folders and files, and how much of that is only cached and can be reclaimed; it and its folders show when their newest copy came. Forget and Keep offline work here too, and Clear… on a server's row removes everything held from it.

Files you only opened are removed when they take more than 500 MB (200 MB on Android) — the oldest first — and Android may remove them when it needs room. Files you keep offline are never removed for you. A copy whose file has changed on the server says so, and is refreshed the next time you open the file there, or by Update on its line.

Each server

On the server's Server tab, Cache this server's files turns it off for that server: nothing from it is stored on this device. Below it, how much it takes here and Clear cache…. Deleting a server removes its cache.
