Telechore Usage What's new

Files offline

What you open on a server is kept on this device for a while, so the server can be browsed when it cannot be reached, and a file that has not changed is not fetched again.

A row's ⋯

Each row in a server's folder ends in ⋯. It opens a strip under the row: first what this device has of it — No copy on this device, or Copy from and when — then what you can do:

  • Forget copy removes the copy on this device. Nothing on the server changes.
  • Keep offline keeps the file on this device until you forget it. It is lit while the file is kept, and a bookmark follows the file's name. Press it again to stop keeping it. A file's own page has the same button.
  • Download saves a copy where you choose: a folder on a desktop, and the system's Save to… sheet on Android.
  • Delete… deletes the file, or an empty folder, from the server. It asks every time. A copy you kept offline stays, in Cache.

When the server cannot be reached

A server's folder opens from what this device has, with cannot be reached over the page and when the copy is from. Folders you never opened, and files you never fetched, are grey. Try again connects once the network is back.

Cache

Cache, in Places, lists the servers this device holds files from. Inside a server, each folder with a copy is one row, named by its path on the server — a long one with its start cut, … › pi › src — and inside that, its copies. Forget and Keep offline work here too, and Clear… on a server's row removes everything held from it.

Files you only opened are removed when they take more than 500 MB (200 MB on Android) — the oldest first — and Android may remove them when it needs room. Files you keep offline are never removed for you. A copy whose file has changed on the server says so, and is refreshed the next time you open the file there.

Each server

On the server's Server tab, Cache this server's files turns it off for that server: nothing from it is stored on this device. Below it, how much it takes here and Clear cache…. Deleting a server removes its cache.
